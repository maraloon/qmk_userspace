# Раскладка Charybdis 4×6 (кеймап `orthodox`)

сплит-эрго с трекболом на правой половине.

### Общие особенности
- Graphite раскладка. Намного удобнее colemak
- Не нужно держать mod-клавиши зажатыми, все на OSL (one shot layer) и хаках к нему (см. mixed режим для Num и CapsWord для SHIFT). Смысл: чем меньше разновидностей способов набора (click, hold, tap-dance, combo), тем ментально проще
- А вот переключение языка как-раз на hold. Cмысл: Это полностью исключает проблемы связанные с "забыл переключить раскладку"
- в противовес =раскидать все по слоям= тут максимально используются все клавиши одного слоя. Смысл: в случаях когда вводимый текст состоит из набора букв, символов и цифр в перемешку, это намного проще, чем постоянно переключаться между слоями. Пример: в vim: `:e %:h/file.c` - открыть file.c из текущей дирректории
- одна клавиша используется для входа в слой (символов или цифр) по click, для lock'а слоя по double-click (тайминг в 400ms), и выход из слоя по повторному клику

### Трекбол
- L_CLK поближе, R_CLK как очень редкий подальше. Оба на главном слое
- для скролинга нажать Sym. Еще раз нажать, чтобы выйти
- так-же есть Vol и Scl для изменения громкости и масштаба с помощью трекбола

                     └──────┴──────┴──────┘   └──────┴──────┘
                            ┌──────┬──────┐   ┌──────┐
                            │L_CLK │SHIFT │   │ LANG │

- раскладка Graphite, с небольшими изменениями. Самые редкие Z и J вынесены подальше в угоду более частым символам
- вывод большинства частых символов на основной слой, чтобы избежать перепрыгивания из ABC в SYM и обратно. Пример: `:e %:h/`, `name@mail.com` (@ на слое sym, но нажимется очен удобно), `cd ~/code/.dotfiles/some-file.com`
- C⌫ - удаление слова. Как основной способ удаления ошибки. На практике часто быстрее напечатать слово заново по мышечной памяти, чем удалить пару символов и переписать часть слова
- ⌘W - вход в режим submap (как leader key) в hyprland из которого происходит все управление hyprland'ом
- Sym, Num, Tmux и Ctrl работают как one-shot-layer. Особенность этой раскладки, что практически не надо делать hold операции, кроме тех случаев, где от этого выигрыш (см. LANG)
- SHIFT. Работает как обычно, если зажать. Если кликнуть, то следущая буква будет большой, если дабл-клик, то все следущее слово будет в upper-case (гугли QMK CapsWord)
- LANG работает как переключение на русский, но только по удержанию этой клавиши. Отпустишь - возвращает на eng. Это полностью исключает проблемы связанные с "забыл переключить раскладку", а так-же не надо париться на счет расположения символов на этом слое
- ! и ? расположены вокруг Enter для отправки сообщений, завершающихся этими символами
- #vim: пара # и * для поиска позади/впереди текущей позиции в документе
- одинарная кавычка (а не что-то более частое) расположена на большом пальце справа, только потому что у меня эта клавиша плохо спаяна и работает через раз. По остаточному признаку

слой очень заточен под vim
При клике на Num из слоя ABC происходит переход в NUM в mixed режиме. В нем
слой остается активным при нажатии 0-9 и символов, и происходит выход в ABC при
нажатии стрелок, Enter, Esc, G. Это позволяет:
- прыгать в vim по строкам: 14▼, 3▲. Например для перехода на 14 строк вниз и
  входа в режим insert последовательно нажимаются: Num, 1, 4, down, i. Никаких
  hold-ов и лишних выходов из слоя
- перейти на конретную строку: 567g
- если нужен обычный залоченный NUM, то просто делаем double-click по Num из
  ABC. Теперь можем пользоваться стрелочками свободно
- выход из слоя происходит так-же по Num

- цифры расположены так, чтобы вводить последовательности с минимальным движением пальцев. 7 и 8 поменяны местами просто потому что, мой мозг их путал постоянно
- символы продублированны из ABC (тут не указаны, чтобы не зашумлять вид)

```
┌──────┬──────┬──────┬──────┬──────┬──────┐   ┌──────┬──────┬──────┬──────┬──────┬──────┐
│      │      │      │      │      │      │   │      │      │ Enter│      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤   ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │  <   │  >   │  &   │  |   │      │   │      │      │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤   ├──────┼──────┼──────┼──────┼──────┼──────┤

├──────┼──────┼──────┼──────┼──────┼──────┤   ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │  [   │  ]   │  (   │  )   │  +   │   │      │  @   │Sym   │ Num  │      │      │
└──────┴──────┴──────┴──────┴──────┴──────┘   └──────┴──────┴──────┴──────┴──────┴──────┘
                     ┌──────┬──────┬──────┐   ┌──────┬──────┐
                     │  ⌫   │  ␣   │  ,   │   │Esc   │      │
                     └──────┴──────┴──────┘   └──────┴──────┘
                            ┌──────┬──────┐   ┌──────┐
                            │ Vol  │  Scl │   │      │
                            └──────┴──────┘   └──────┘
```

- в SYM заходит в режиме OSL: клик по Sym переходит на слой, нажатие на символ вводит этот символ и происходит выход в слой ABC
- Для lock'а слоя надо сделать double-click по Sym
- для выхода из слоя снова нажать на Sym
- символы из ABC так-же продублированы в слое (тут не указаны, чтобы не зашумлять вид)
- ^ и $ - это переход в начало/конец строки в vim
- заметьте, @ очень удобно вводить: Sym, @
- `Vol` — трекбол = громкость, `Scl` — трекбол = зум (Ctrl+− / Ctrl+=).

В tmux все управление не на leader-key (ctrl-b по умолчанию), а на alt и alt+shift (переключение проекта)

- Tmux, space, n (посылает alt+shift+n): открыть проект notes
